## 1. Offensive Security (공격 보안 - Red Team)

시스템의 취약점을 선제적으로 찾아내어 방어력을 높이는 '화이트 해커'의 전형적인 역할입니다.

* **모의해킹 전문가 (Penetration Tester):** 사전에 승인된 범위 내에서 시스템, 네트워크, 웹/앱에 직접 침투하여 취약점을 분석하고 보고서를 작성합니다.
* **레드 팀 전문가 (Red Teamer):** 특정 대상을 정해두지 않고, 실제 해커와 유사한 시나리오로 기업 전체의 보안 대응 능력을 테스트합니다.
* **취약점 분석가/연구원 (Vulnerability Researcher):** 소프트웨어나 하드웨어의 알려지지 않은 보안 결함(Zero-day)을 심층 분석합니다.
* **버그 바운티 헌터 (Bug Bounty Hunter):** 기업이 공개한 프로그램의 버그를 찾아 보상금을 받는 독립적 활동가입니다.

### 업무/일과

주로 프로젝트 단위로 움직이며, 타겟 시스템의 허점을 찾는 데 집중합니다.

**모의해킹/레드팀:** 
* **오전:** 고객사 범위(Scope) 확인, 최신 취약점 트렌드(Exploit) 리서치.
* **오후:** 타겟 시스템 침투 시도 (웹, 앱, 네트워크), 권한 상승 시나리오 수행.
* **마무리:** 침투 성공 경로 기록 및 보안 대책(Patch) 방안 정리, 고객사 보고서 작성.

**취약점 연구/버그바운티:**
* **루틴:** 특정 소프트웨어(OS, 브라우저 등)를 분해(Reverse Engineering)하거나 퍼징(Fuzzing) 도구를 돌려 예외 상황 발생 모니터링. 성공 시 PoC(증명 코드) 작성.

## 2. Defensive Security (방어 보안 - Blue Team)

외부 침입을 실시간으로 감시하고, 공격이 발생했을 때 시스템을 보호하는 역할입니다.

* **보안 관제 분석가 (SOC Analyst):** 보안 운영 센터(SOC)에서 24시간 모니터링을 통해 이상 징후를 탐지하고 초동 조치를 수행합니다.
* **보안 엔지니어 (Security Engineer):** 방화벽(Firewall), 침입 탐지 시스템(IDS/IPS), 백신 등 보안 솔루션을 설계하고 운영합니다.
* **침해 사고 대응 전문가 (Incident Responder):** 해킹 사고 발생 시 현장에 투입되어 공격 경로를 차단하고 시스템을 복구합니다.
* **위협 헌터 (Threat Hunter):** 자동화 도구가 잡지 못한 잠재적 위협을 시스템 내부에서 능동적으로 찾아내는 고숙련 전문가입니다.

###업무/일과

교대 근무(SOC)가 있거나, 사건 발생 시 즉각 대응해야 하는 긴박함이 있습니다.

**보안 관제(SOC Analyst):**
* **오전/교대:** 이전 근무자로부터 탐지된 이상 이벤트 인수인계.
* **일과:** 모니터링 대시보드(SIEM)의 알람 분석, 오탐(False Positive) 제거, 위험 이벤트 차단 정책 적용.
* **마무리:** 일일 보안 동향 보고서 작성 및 위협 IP 블랙리스트 업데이트.


**침해 사고 대응(IR):**
* **평시:** 사고 대응 매뉴얼(Playbook) 최신화, 모의 훈련 실시.
* **비상시:** 현장 출동, 공격 로그 분석, 악성 파일 유포지 차단, 피해 시스템 격리 및 복구 지원.


**위협 헌팅:**
* **루틴:** EDR(단말 대응 솔루션) 데이터를 쿼리로 조회하여 "알람은 안 떴지만 내부에 숨어있을지 모르는" 공격자의 흔적(Artifact) 추적.

## 3. Governance, Risk & Compliance (GRC - 관리 보안)

기술적인 부분뿐만 아니라 법률, 정책, 위험 관리를 통해 기업의 보안 체계를 설계합니다.

* **정보보호 컨설턴트 (Security Consultant):** 기업의 보안 수준을 진단하고, ISMS-P 등 국내외 인증 취득을 위한 전략을 컨설팅합니다.
* **보안 감사인 (IT Auditor):** 기업이 보안 규정과 법적 요구사항(GDPR, 개인정보보호법 등)을 잘 지키고 있는지 검토합니다.
* **보안 정책 담당자 (Security Policy Officer):** 사내 보안 규정, 임직원 보안 교육 및 인식 제고 프로그램을 기획합니다.
* **개인정보보호 전문가 (Privacy Specialist):** 데이터 활용 시 개인정보 유출 방지를 위한 비식별화 기술 적용 및 법적 검토를 담당합니다.

### 업무/일과

회의와 문서화가 업무의 80%를 차지하며, 소통 능력이 중요합니다.

**보안 컨설턴트/감사인:**
* **오전:** 고객사 담당자 인터뷰 및 현장 점검.
* **오후:** 법적 준거성(ISMS-P 등) 대비 미흡 사항(Gap) 분석, 증적 자료(로그, 문서) 검토.
* **마무리:** 향후 보안 로드맵 제시 및 컨설팅 결과 보고서 작성.


**개인정보보호 담당자:**
* **루틴:** 신규 서비스 출시 전 개인정보 영향평가 실시, 개인정보 처리방침 업데이트, 임직원 보안 교육 콘텐츠 기획.

## 4. Infrastructure & Cloud Security (인프라 및 클라우드 보안)

IT 인프라의 근간이 되는 네트워크와 최신 클라우드 환경을 보호합니다.

* **클라우드 보안 엔지니어 (Cloud Security Engineer):** AWS, Azure, GCP 등 클라우드 환경에서 보안 설정(IAM, VPC 등)을 최적화합니다.
* **네트워크 보안 전문가 (Network Security Specialist):** 네트워크 트래픽을 분석하고 데이터 전송 구간의 암호화 및 안전성을 책임집니다.
* **DevSecOps 엔지니어:** 소프트웨어 개발(Dev)과 운영(Ops)의 모든 단계에 보안(Sec) 프로세스를 자동화하여 통합합니다.

### 업무/일과

시스템 운영과 보안의 접점에서 기술적인 설정을 최적화합니다.

**보안 엔지니어:**
* **오전:** 보안 장비(방화벽, WAF, IPS) 헬스체크 및 리소스 모니터링.
* **오후:** 신규 서비스 오픈에 따른 방화벽 정책(ACL) 허용 검토 및 적용.
* **마무리:** 장비 펌웨어 업데이트 스케줄링 및 보안 벤더사 기술 미팅.


**DevSecOps 엔지니어:**
* **루틴:** 개발자의 코드 배포 파이프라인(CI/CD)에 자동 보안 스캔 도구 통합, 취약한 라이브러리 사용 여부 자동 점검 스크립트 작성 및 개선.

## 5. Software & Application Security (S/W 및 앱 보안)

프로그램이 만들어지는 단계부터 보안이 고려되도록 관리합니다.

* **애플리케이션 보안 분석가 (AppSec Analyst):** 소스 코드 내의 취약점을 분석(SAST/DAST)하고 보안 코딩 가이드를 제시합니다.
* **보안 소프트웨어 개발자 (Security Software Developer):** 암호화 도구, 보안 에이전트, 백신 프로그램 자체를 개발합니다.
* **암호 전문가 (Cryptographer):** 새로운 암호 알고리즘을 설계하거나 기존 알고리즘의 안전성을 검증합니다.

### 업무/일과

코드와 씨름하며 개발 단계부터 보안을 내재화합니다.

**AppSec 분석가:**
* **루틴:** 소스 코드 진단 도구 결과를 검토하여 개발자에게 수정 가이드 제공, 보안 코딩 가이드라인 수립.


**보안 S/W 개발자:**
* **루틴:** 암호화 모듈 개발, 보안 에이전트 성능 최적화, 보안 위협 탐지 알고리즘 코딩.


**암호 전문가:**
* **루틴:** 최신 양자 내성 암호 연구, 사내 표준 암호화 방식 검증, 난수 생성기 성능 테스트.

## 6. Investigation & Specialized Roles (수사 및 특수 분야)

사고 이후의 증거 수집이나 특정 하드웨어에 특화된 분야입니다.

* **디지털 포렌식 전문가 (Digital Forensic Examiner):** 디지털 증거를 수집, 복구, 분석하여 법적 증거력을 갖춘 보고서를 작성합니다.
* **악성코드 분석가 (Malware Analyst):** 발견된 바이러스나 랜섬웨어를 역공학(Reverse Engineering)하여 작동 원리와 치료법을 찾아냅니다.
* **제어시스템(OT/ICS) 보안 전문가:** 발전소, 공장 등 국가 중요 시설의 산업 제어 시스템을 보호합니다.
* **AI 보안 전문가:** AI 모델에 대한 공격(Adversarial Attack)을 방어하거나, AI를 활용해 보안 위협을 자동 탐지합니다.

### 업무/일과

고도의 전문성을 바탕으로 사후 분석 및 연구에 집중합니다.

**악성코드 분석가:**
* **루틴:** 수집된 의심 파일을 샌드박스에서 실행(동적 분석), 디버거로 어셈블리 코드 확인(정적 분석), 해당 파일의 C2 서버(명령 제어 서버) 주소 추출.


**디지털 포렌식 전문가:**
* **루틴:** 압수된 매체(PC, 모바일)의 이미징(복제), 삭제된 파일 복구, 타임라인 분석을 통한 행위 입증, 법적 효력을 갖는 분석 결과서 작성.


**OT/ICS 보안 전문가:**
* **루틴:** 공장/발전소 현장 점검, 폐쇄망 환경에서의 보안 패치 적용 방식 검토, 산업용 프로토콜(Modbus 등) 이상 징후 분석.

### 🔍 항목별 상세 해설

#### 1. 취업 및 업무 난이도

* **공격 보안 & 수사:** 타고난 감각과 깊은 기술적 구력을 요하기 때문에 진입 장벽이 매우 높습니다. 반면 **방어 보안(보안 관제)**은 신입 채용 규모가 커서 진입이 상대적으로 수월하지만, 업무 난이도는 실시간 상황 대응 때문에 매우 높습니다.
* **GRC:** 기술적 깊이보다는 법과 규제, 비즈니스 프로세스를 이해하는 능력이 중요하여 비전공자가 보안으로 전입할 때 가장 많이 선택합니다.

#### 2. 샐러리 (연봉 및 보너스)

* **인프라/클라우드:** 최근 기업들의 클라우드 전환 가속화로 몸값이 가장 가파르게 상승 중입니다.
* **공격 보안:** 'S급' 인재에 대한 대우가 가장 확실하며, 버그 바운티 등을 통한 추가 수익 창출 기회도 열려 있습니다.
* **GRC:** 초봉은 타 직군 대비 낮을 수 있으나, 경력이 쌓여 컨설팅이나 C-Level(CISO)로 올라갈 경우 안정적이고 높은 연봉을 보장받습니다.

#### 3. 진급 및 커리어 확장성

* **GRC:** 기업 전체의 보안 거버넌스를 다루기 때문에 **CISO(최고정보보호책임자)**가 되기에 가장 유리한 루트입니다.
* **방어 보안:** 실무 현장을 꿰뚫고 있어 보안 팀장이나 운영 관리자로 성장하기 좋습니다.
* **S/W 보안:** 개발과 보안을 모두 알기 때문에 테크 리드나 기술 경영자로의 확장이 용이합니다.

#### 4. 사회적 인지도 및 스트레스

* **공격 보안/수사:** 미디어나 대중에게 '화이트 해커', '디지털 포렌식'으로 가장 멋있게 비춰지지만, 그만큼 기술적 한계에 부딪혔을 때의 스트레스가 큽니다.
* **방어 보안:** "잘하면 본전, 뚫리면 죄인"이라는 인식 때문에 사고 발생 시 엄청난 정신적 압박을 받습니다. 특히 24시간 교대 근무가 동반되는 경우가 많습니다.

* **"나는 사람들과 소통하고 법과 규정을 체계적으로 정리하는 게 적성에 맞다"** ➔ **GRC(컨설팅/관리)**
* **"나는 시스템 구조를 설계하고 최신 클라우드 기술을 다루고 싶다"** ➔ **클라우드/DevSecOps**
* **"나는 현장의 긴박함을 즐기고 실시간으로 공격을 막아내고 싶다"** ➔ **방어 보안(SOC/IR)**

## 1. 커리어 패스 및 성장 가능성 비교

"내가 10년 뒤에 어떤 모습으로 성장해 있을 것인가?"에 대한 해답입니다.

| 직종 카테고리 | **C-Level(CISO) 유리도** | **지식의 수명 (Longevity)** | **글로벌/프리랜서 확장성** |
| --- | --- | --- | --- |
| **공격 보안** | 중 (기술 고문/CTO 성향) | **단기** (매일 새로운 취약점 공부) | **최상** (기술은 국가 장벽이 없음) |
| **방어 보안** | 중상 (운영 총괄 책임) | **중기** (공격 트렌드에 종속됨) | **중** (현지 SOC 환경에 의존) |
| **관리 보안(GRC)** | **최상** (경영진의 언어 사용) | **장기** (법과 원칙은 쉽게 안 변함) | **중하** (국가별 법령에 국한됨) |
| **인프라/클라우드** | 상 (인프라 총괄 겸임 가능) | **중기** (클라우드 아키텍처 중심) | **상** (AWS/Azure는 전 세계 공통) |
| **S/W 및 앱 보안** | 중상 (개발 실장/CTO 트랙) | **중단기** (언어/프레임워크 변화) | **상** (개발 역량 기반 해외 취업) |
| **수사/특수 분야** | 중 (기관장/전문가 그룹) | **장기** (기초 원리는 변하지 않음) | **중** (사법 체계/수사권 문제) |

* **핵심 분석:** * **CISO가 목표라면?** 경영진에게 보안 리스크를 '돈'과 '법'의 관점으로 설명해야 하는 **GRC**가 가장 유리합니다.
* **디지털 노마드가 꿈이라면?** 장소에 구애받지 않고 실력만으로 증명하는 **공격 보안**이나 **S/W 보안**이 유리합니다.
* **공부 스트레스를 줄이고 싶다면?** 기술 변화 속도가 상대적으로 느리고 관리 중심인 **GRC**나 **수사 분야**가 적합합니다.

## 4. 기술적 적성 확인 (코딩 및 문제 해결 방식)

"매일 아침 출근해서 내 뇌를 어떻게 사용할 것인가?"에 대한 해답입니다.

### 💻 코딩(Coding) 활용도 비교

보안이라고 다 코딩을 잘해야 하는 것은 아닙니다. 본인의 코딩 선호도에 따라 선택하세요.

1. **High Coding (직접 개발/분석):** * **S/W 보안:** 보안 엔진을 만들거나 소스 코드의 허점을 찾아야 하므로 개발자 수준의 코딩 능력이 필수입니다.
* **악성코드 분석:** 어셈블리어부터 C, Python까지 깊게 파고들어 코드를 '해부'해야 합니다.


2. **Middle Coding (스크립트/자동화):**
* **공격 보안:** 기존 도구를 개조하거나 침투 시나리오를 자동화하는 Python 스크립트 능력이 중요합니다.
* **인프라/클라우드(DevSecOps):** 'Code로서의 인프라(IaC)'를 다루기 위해 자동화 코드를 작성합니다.


3. **Low Coding (도구 활용/문서):**
* **방어 보안(관제):** 직접 코딩하기보다 보안 솔루션이 주는 알람을 분석하고 쿼리(SQL 등)를 던지는 업무가 많습니다.
* **GRC:** 코드를 짜는 일은 거의 없으며, 코드 진단 결과 보고서를 읽고 관리적 대책을 세우는 업무가 중심입니다.

### 🧠 문제 해결 방식 (Mindset)

본인이 어떤 상황에서 카타르시스를 느끼는지 확인해 보세요.

* **파괴적 혁신형 (Breaker):** "이 단단해 보이는 성벽을 어떻게 무너뜨릴까?"
* **해당 직종:** 공격 보안(모의해킹), 취약점 연구.
* **성향:** 집요함, 창의적 사고, 정답이 없는 문제에 도전하는 즐거움.


* **수호적 관리형 (Builder/Protector):** "어떻게 하면 단 한 명의 침입자도 못 들어오게 빈틈없이 설계할까?"
* **해당 직종:** 방어 보안, 인프라 보안, S/W 보안.
* **성향:** 꼼꼼함, 체계적인 시스템 설계 선호, 안정성에서 오는 만족감.


* **중재 및 조정자형 (Governor):** "전체 조직이 안전하게 돌아가려면 어떤 규칙과 시스템이 필요할까?"
* **해당 직종:** GRC, 보안 컨설팅.
* **성향:** 논리적 설득력, 전체를 조망하는 시야, 법과 원칙 준수.
